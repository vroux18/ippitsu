# Ippitsu 一筆

Roguelite d'action sur téléphone, jouable d'un seul doigt : on pose le doigt, le temps ralentit, on trace son chemin d'encre, on lâche… et le héros fonce le long du trait en tranchant tout.

- **APK Android** (dernière version) : https://github.com/vroux18/ippitsu/releases/latest/download/Ippitsu.apk
- **Version web** : https://vroux18.github.io/ippitsu/

Godot 4.7 (GDScript, rendu Compatibility). Tout est compilé par GitHub Actions à chaque push sur `main` (`.github/workflows/build.yml`).
