# Audit décors, énigmes et code (9 octobre 2026)

Lecture seule du code. Les numéros de ligne sont approximatifs : chercher par nom de fonction.

## Décors : règle d'uniformisation (6 couches, tous mondes)
1. **Sol** : une matière propre à chaque monde, saturation et valeur moyennes. Jamais rouge, or ou émissif.
2. **Bordure** : liseré sumi identique partout, flanc = teinte du sol assombrie. Bois des ponts teinté par monde (nouvelle clé `bridge_wood`).
3. **Vide** : défini par `water_style` seulement. Un prop dans le vide repose sur un socle, et sa hauteur se calcule à partir de ce socle.
4. **Repères** (torii de sortie, haies, recoins) : code commun, sumi + or, sans vermillon.
5. **Fond lointain** : la seule couche où le vermillon est permis.
6. **Props de gameplay** : socle cerné d'encre, ≤ 0,6 m, palette du monde, aucun émissif chaud sauf les dangers.

Outillage proposé :
- tables de props par monde avec étiquettes (`snow`, `ninja`, `sea`, `fire`, `newyear`) ;
- une liste `forbid` par monde ;
- un contrôle CI qui refuse les étiquettes interdites et les couleurs proches de #D7372B ou #C49A45 dans les couches 1, 2, 4 et 6.
